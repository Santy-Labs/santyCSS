CHANGELOG

Version History

All notable changes to SantyCSS are documented here. Follows Semantic Versioning.

ℹ️

About version numbering

This changelog documents major feature releases (even minor versions: v1.0, v1.2, v1.4 …). Odd minor versions such as v1.1, v1.3, v1.5, and v1.7 were internal patch releases — small bug fixes and micro-improvements that did not introduce new features — and are therefore not listed separately here.

★

v2.7.0

Latest

Released July 2026

  • New:has() parent variants — style a parent from its children with has-checked:, has-focus:, has-invalid:, has-hover: + 6 more, plus group-has-*: — zero-JS form & card states
  • New9 new components — .toast (stacked notifications), .switch, .checkbox / .radio (custom styled), .range slider, .carousel (pure-CSS scroll-snap), native .dialog with ::backdrop, native .popover, .file-drop zone
  • NewSemantic theming — .background-surface, .color-text, .color-text-muted, .border-color-default consume design tokens and flip automatically with .dark or data-theme
  • Newsanty-themes.css — 5 prebuilt theme presets: Ocean, Sunset, Forest, Midnight, Mono — <html data-theme="ocean"> and done
  • Newsanty-classmap.json — all 21,000+ class names as JSON for editor IntelliSense, linters & AI tooling (santycss/classmap)
  • NewCLI — npx santycss init scaffolds a CDN-wired starter page; npx santycss classes prints the class inventory; purge flags unchanged
  • NewTest suite — 83 build-output regression tests (npm test) covering utilities, variants, components, themes, classmap & package exports
  • Fixtransition-all was documented but never generated — now emitted (plus new transition-shadow)
  • FixTemplates page "Copy Code" — copied HTML linked local santy.css paths that 404'd outside the site; links are now rewritten to CDN URLs on copy, with clipboard fallback and file:// handling
